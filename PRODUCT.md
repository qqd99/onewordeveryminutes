# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Language learners studying vocabulary and reviewing words over time. The current user wants to reuse the dictionary when learning additional languages.

## Product Purpose

Vocabulary SRS combines word study, spaced repetition, pronunciation and an offline multilingual dictionary.

## Capabilities and Constraints

- Learning and meaning selectors choose language columns from shared, concept-aligned vocabulary rows.
- 356 published language columns cover 1,514 concept rows. Source varieties and transcriptions remain distinct, and published dictionaries supplement the rows.
- Assistant-generated translations are activated directly at the user's request. The initial batch has 80 concepts in 40 modern languages, giving 371 combined columns. Origin and partial coverage remain visible.
- Coverage differs by populated column combination. Missing cells are disclosed and excluded from study.
- Progress, preferences and independent save slots persist in the browser and support JSON backups.
- Study supports word-to-meaning, meaning-to-word and picture quiz directions, with audio and recent-word loops.
- The site uses HTML, CSS and vanilla JavaScript. Both publication directories must match byte for byte.
- Keyboard study controls, responsive layouts and light and dark themes are existing capabilities.

## Brand Commitments

The user requested a minimalist redesign and selected a focus on one word at a time, with review tools placed below the main task. The user confirmed a shared spreadsheet-like data model while retaining the study screen.

## Product Principles

- Center the current word and the learner's next action.
- Keep dictionary source attribution and coverage visible where relevant.
- Preserve review history and independent learning saves.
- Make secondary tools available through clear, familiar controls.
