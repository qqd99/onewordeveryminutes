# Vocabulary app

## Mode

Operate

## Confirmed brief

Redesign the existing application in a minimalist style. Prioritize one word at a time. Place recent-word practice below the study task.

## Primary path

Choose learning and meaning language columns, start a session, read one prompt, answer, and continue. Word list, dictionary, statistics, preferences and backups remain available through the main navigation.

## Required states

Idle, loading, active study, answered, paused, empty coverage, dictionary result, missing entry, and light and dark themes. Support narrow mobile screens and keyboard navigation.

## Build approach

Implement directly in the existing HTML, CSS and JavaScript, and verify the rendered application through automated browser checks.
