Learning Mode

Mode 1: Chinese → localized meaning. Mode 2: localized meaning → Chinese. Mode 3: Chinese → picture; the localized text meaning appears after answering. Mode 3 searches openly licensed photos on Wikimedia Commons for the current word and keeps two locally saved distractors. Internet access is needed for uncached words. Approve an appropriate image to reuse it later in this browser. Your selection is saved until changed.

Internet picture search (Mode 3)

Pictures for the current word are searched on Wikimedia Commons, without any API key or Gemini quota. Only the correct-word photo can be judged and approved; the other two are local distractors. After answering, choose Good to save the photo in this browser, or Bad to find another. Source and license links are provided with each photo.

Approved photos can be shared across devices only if a separate shared database endpoint is configured. Without one, approvals remain on the current device.

Meaning language

With Chinese vocabulary, Chinese words and sentences are translated directly to Vietnamese or your selected language—not via English. Original English definitions stay available offline if translation fails.

Chrome and supported desktop browsers can download a language pack once, then translate without relying on public translation services. No account needed.
