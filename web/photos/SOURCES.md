# Photo dataset sources and rights

These are **photographs**, not emojis or pictograms. All images are checked into this website at `photos/*.jpg`. The quiz does **not** search Google or query an image API when displaying a card. Google image search results by themselves do not grant redistribution rights.

There are **56 curated photographs**. Only exact Chinese words and exact English meanings curated in `picture-catalog.js` are eligible in picture mode. All other words remain usable in text modes.
